# 📱 Telecom Customer Churn & Revenue Analytics

## 📊 Project Overview
An end-to-end churn analytics project analyzing **5,000 customers, 200,000 usage records, 60,000 bills, and 10,000 complaints** for a telecom company operating in Saudi Arabia.

## 🎯 Business Problem
- 30% churn rate causing significant revenue loss
- No understanding of why customers leave
- Difficulty identifying at-risk customers before they churn
- No visibility into ARPU and revenue trends per plan

## 🛠️ Tools & Technologies
- **MySQL:** 5 interconnected tables (customers, plans, usage, bills, complaints)
- **SQL:** Advanced queries (Cohort Analysis, Churn Rate, ARPU, RFM Analysis, Window Functions)
- **Power BI:** DAX measures, Decomposition Tree, Smart Narrative, Drill-through, Waterfall Chart
- **Data Storytelling:** Strategic retention recommendations for management

## 💡 Recommendations
1. **Launch Loyalty Program** for long-term customers
2. **Speed up complaint resolution** (target: 3 days instead of 15)
3. **Target At-Risk Customers** (2+ complaints + late payments) with proactive offers
4. **Upgrade Prepaid Customers** to Postpaid (lower churn rate)
5. **Launch Bundles** (calls + data + fiber) to increase ARPU

## 📈 Key Features

- **Revenue Analysis:** Monthly trends, ARPU, top customers
- **Usage Analytics:** Data usage per plan, monthly trends
